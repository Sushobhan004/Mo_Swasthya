Mathematical & Algorithmic Architecture

Mo Swasthya Deterministic Zero-Cloud Multi-Engine Core
1. Deterministic NLP Tokenizer & Negation Scope (NegEx Variant)
Time: O(N) Latency: < 0.8 ms

Scans patient symptom narratives, strips punctuation boundaries, detects triggers (no, not, denies, free of) and applies windowed forward negation scope without LLM hallucinations.

Scope(w_i) = [i + 1, min(i + k, BoundaryIndex)], where k = 6 tokens, Boundary = {'.', ',', ';', 'but', 'except'}
2. Probabilistic Inverted Search: Okapi BM25
Time: O(|Q| · avg(df)) Latency: < 1.8 ms

Powers the Medical Atlas search over WHO & ICMR topics with non-linear term frequency saturation and document length normalization.

Score(D, Q) = Σ IDF(q_i) · [ f(q_i, D) · (k1 + 1) ] / [ f(q_i, D) + k1 · (1 - b + b · |D| / avgdl) ] | k1=1.2, b=0.75
3. Clinical Knowledge Graph & Weighted Multi-Hop BFS
Time: O(|V| + |E|) Latency: < 2.4 ms

Represents 115+ clinical nodes (Symptoms, Anatomy, Conditions, Red-Flags) as a bipartite weighted graph with pathognomonic link coefficients and negative penalty factors.

Score(C) = [ Σ w(s, C) · α(s) ] / [ Σ w(s, C) ] - λ · Σ w(s_negated, C) | λ=0.65 penalty factor
4. Deterministic Risk Rule Engine & Emergency Cascade
Time: O(1) Latency: < 0.1 ms

Guarantees immediate zero-latency escalation for life-threatening conditions (ACS, FAST Stroke, Tension Pneumothorax, Acute Appendicitis, Snakebite, Poisoning).

Risk Tier = IF(Any(RedFlag_Active) == True) ➔ URGENT(112/108 SOS) ELSE IF(Score ≥ 0.65) ➔ CAUTION ELSE ➔ ROUTINE
5. Geodesic Haversine Distance & A* Shortest Path Router
Time: O(|E| + |V| log |V|) Latency: < 3.2 ms

Calculates exact spherical terrestrial distances and navigates offline road graphs with dynamic roadblock penalties Ω(n).

d = 2R · arcsin(√(sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2))) | f(n) = g(n) + h(n) + Ω(n)
6. Edge Vision Laplacian Blur Gating & RMS Contrast
Time: O(M × N) Latency: < 12.5 ms

Performs local 2D discrete Laplacian convolution filtering to reject blurry or underexposed imagery prior to neural feature extraction.

∇²I = [ [0,1,0], [1,-4,1], [0,1,0] ] * I(x,y) | Blur Var = Var(∇²I) ≥ 120.0 Threshold Gate
